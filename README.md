# Data Analysis Projects 


This repository contains beginner-friendly data analysis projects focused on extracting meaningful insights from real-world and synthesized datasets using Python.

---

## Projects Included

### 1. Netflix Data Analysis 

#### Overview
Analyzed the Netflix Movies and TV Shows dataset to explore trends and patterns in streaming content.

#### Key Analysis Performed
- Explored content types (Movies vs TV Shows)
- Analyzed genre distribution
- Studied release year trends
- Identified top countries producing Netflix content
- Examined ratings and audience categories
- Performed data cleaning and preprocessing

#### Skills Used
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Trend Analysis

---

### 2. API Log Data Analysis 

#### Overview
Worked with synthesized API log datasets to analyze request patterns and extract useful insights.

#### Key Analysis Performed
- Cleaned and processed log data
- Analyzed API request trends
- Explored response patterns
- Identified usage behavior and activity trends
- Visualized findings using graphs and charts

#### Skills Used
- Data Preprocessing
- Log Analysis
- Pattern Recognition
- Data Visualization
